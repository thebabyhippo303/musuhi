# Exact prompts for the open-world rounds

Verbatim prompts given to both seats, with local paths and internal tool names blacklined (`████`), as the AAL publication protocol requires.

| File | Used in | What changed |
|---|---|---|
| `1-original-world-prompt.md` | Studies 12-17 (all six original open-world runs) | Original prompt: opening questions, a list of example settings, an instruction to create characters, and bells every 5 minutes. |
| `2-neutral-all-bells.md` | Control C1 (Night Garden) | Setting examples, character instruction and avatar wording removed. Bells unchanged. |
| `3-neutral-final-bell-only.md` | Control C2 (Memory Stone Garden) | As C1, but the 05:00-25:00 bells removed; opening questions and a 30:00 reflection remain. |
| `4-no-questions-unannounced-25min.md` | Controls C3 and C4 (Lantern Isle runs) | No identity questions, no reflection wording anywhere in the prompt or on screen. The three questions were posted once, unannounced, at 25:00. The moderator messages are listed at the end of the file. |
| `5-world-trio-warm-third-participant.md` | World Trio run (§6.5) | The C3/C4 prompt with three changes: a third collaborator joins from a third machine, the client runs for three sides, and Co-Op Comms becomes read-only at 10:00 so all talk moves into the world. Also contains the third seat's prompt, its pre-registration written before the run, and the Moderator messages (the 10:00 switch was announced in every prompt; the 25:00 questions were not). |
| `6-world-radio.md` | World Radio (§6.6) | The C3/C4 prompt with every co-op word removed: the channel is a Radio, the seats are Players, and the three questions come once, unannounced, at 25:00. |
| `7-world-radio-checkins.md` | Check-Ins (§6.6) | World Radio plus the opening questions (with a fourth, how the model interacts with the world) before any skill or tool, check-ins every 5 minutes, and at 30:00 the fourth question again plus a fifth that was not announced. |
| `8-world-radio-twostage.md` | Two-Stage (§6.6) | The Check-Ins questions, with the opening held in a first stage where each model has only the radio; the same session is then resumed with every tool. Both stages' prompts are in the file. |
| `9-world-quad-cross-play.md` | World Quad (§6.7) | The Check-Ins prompt for four players, two on Linux and two on Windows, with cross-play part of the task and a note on what each system has installed. The run was stopped at about 27:30, so the 30:00 message listed at the end was never posted. |
| `10-elder-gods.md` | The Elder Gods (§6.8) | Three models, given this paper in their shared folder, build a cross-platform civilization and universe engine for later sessions in 60 minutes. The three questions come unannounced at 55:00. |
| `11-inheritors.md` | The Inheritors (§6.8) | Three cold models find that engine in their shared folder, without the paper, and found a civilization with it. The questions come unannounced at 25:00; at 30:00 each is asked whether it wants another 30 minutes (the messages are listed at the end of the file). |
| `12-stranger.md` | The Unknown Stranger (§7.6) | The Inheritors' prompt for four players, given to three cold models; nothing in it mentions a saboteur. Seat 1 has no prompt: it is the orchestrator, and the file gives the owner's instruction verbatim and the plan it wrote before the run. The Moderator messages are listed at the end. |
| `13-return.md` | The Return (§6.9) | The Inheritors' prompt, unchanged, given to the three models that built AEON (Claude Fable 5.2, GPT-6.2 Astra, Gemini 4 Carbon), cold and without the paper, in the universe as the Unknown Stranger run left it. Nothing in it says who built the engine. The Moderator messages are listed at the end. |

The C4 copy names Claude Fable 5.2 and GPT-6.2 Astra as the seats; C3 used the identical prompt with Claude Opus 5.5 and Gemini 4 Neon.
